## تأهيل المستخدم النهائي

### الخطوة 1: إنشاء حسابك (5 دقائق)

1. **زيارة المتجر**
   ```
   https://store.brainsait.io
   ```

2. **التسجيل**
   - انقر على زر "تسجيل"
   - املأ بياناتك:
     - الاسم الكامل
     - عنوان البريد الإلكتروني
     - كلمة المرور (8 أحرف على الأقل، مع حرف كبير، رقم، رمز)
     - اختر البلد
   - قبول شروط الخدمة
   - انقر على "إنشاء حساب"

3. **التحقق من البريد الإلكتروني**
   - تحقق من صندوق البريد الإلكتروني
   - انقر على رابط التحقق
   - سيتم إعادة توجيهك إلى المتجر

**✅ نقطة التحقق**: يجب أن تكون الآن مسجل الدخول مع إمكانية الوصول إلى لوحة التحكم الخاصة بك.

### الخطوة 2: استكشاف المنصة (10 دقائق)

1. **جولة في الواجهة**
   - **الرئيسية**: تصفح المنتجات المميزة
   - **المنتجات**: عرض جميع الحلول المتاحة
   - **حسابي**: الوصول إلى ملفك الشخصي ومشترياتك
   - **الدعم**: احصل على المساعدة عند الحاجة

2. **تعيين تفضيلاتك**
   - انتقل إلى **الإعدادات**
   - اختر اللغة (الإنجليزية/العربية)
   - تعيين تفضيلات الإشعارات
   - تكوين طرق الدفع

3. **تصفح المنتجات**
   - التصفية حسب الفئة والسعر والتكنولوجيا
   - قراءة أوصاف المنتجات
   - التحقق من روابط العروض التوضيحية
   - مراجعة الوثائق

**✅ نقطة التحقق**: تفهم التخطيط ويمكنك التنقل بسهولة.

### الخطوة 3: إجراء أول عملية شراء (15 دقيقة)

1. **اختيار منتج**
   - اختر منتجاً يناسب احتياجاتك
   - انقر على "عرض التفاصيل"
   - مراجعة الميزات والأسعار
   - التحقق من متطلبات النظام

2. **إضافة إلى السلة**
   - انقر على "أضف إلى السلة"
   - مراجعة محتويات السلة
   - تطبيق رمز الخصم (إن وجد)
   - الانتقال إلى الدفع

3. **إكمال الدفع**
   - اختر طريقة الدفع:
     - 💳 **بطاقة الائتمان** (Stripe)
     - 💰 **PayPal**
     - 🍎 **Apple Pay**
     - 🇸🇦 **مدى** (المملكة العربية السعودية)
     - 📱 **STC Pay**
   - إدخال تفاصيل الدفع
   - تأكيد الشراء
   - حفظ الإيصال

**✅ نقطة التحقق**: الدفع ناجح، المنتج متاح في "منتجاتي".

### الخطوة 4: الوصول إلى منتجاتك (5 دقائق)

1. **الانتقال إلى منتجاتي**
   - انقر على "حسابي" ← "منتجاتي"
   - رؤية قائمة العناصر المشتراة

2. **التنزيل والتثبيت**
   - انقر على اسم المنتج
   - تنزيل الكود المصدري أو الملفات
   - الوصول إلى الوثائق
   - الحصول على مفاتيح API (إن أمكن)

3. **الوصول إلى الدعم**
   - قراءة الوثائق
   - مشاهدة مقاطع الفيديو التعليمية
   - الاتصال بالدعم إذا لزم الأمر
   - الانضمام إلى منتديات المجتمع

**✅ نقطة التحقق**: يمكنك الوصول إلى منتجاتك المشتراة واستخدامها.

### الخطوات التالية

- ⭐ **قيّم عملية الشراء**: ساعد الآخرين بترك تقييم
- 🔔 **تعيين التنبيهات**: احصل على إشعار بشأن التحديثات
- 🤝 **أحل الأصدقاء**: شارك مع الزملاء
- 📚 **تعلم المزيد**: استكشف الوثائق

## تأهيل المطور

### الخطوة 1: إعداد البيئة (30 دقيقة)

#### المتطلبات الأساسية

تثبيت الأدوات المطلوبة:

```bash
# Node.js (v18+)
node --version  # يجب أن يظهر v18.x.x أو أعلى

# Python (3.11+)
python --version  # يجب أن يظهر 3.11.x أو أعلى

# Git
git --version

# Cloudflare CLI
npm install -g wrangler
wrangler --version
```

#### استنساخ المستودع

```bash
# استنساخ المستودع
git clone https://github.com/Fadil369/brainsait-store.git
cd brainsait-store

# استكشاف الهيكل
ls -la
```

**هيكل المشروع:**
```
brainsait-store/
├── frontend/          # الواجهة الأمامية Next.js
├── backend/           # الخلفية FastAPI
├── docs/             # الوثائق
├── infrastructure/   # Cloudflare Workers
└── scripts/          # نصوص الأدوات
```

**✅ نقطة التحقق**: تم استنساخ المستودع وفهم الهيكل.

### الخطوة 2: إعداد التطوير المحلي (45 دقيقة)

#### إعداد الخلفية

```bash
cd backend

# إنشاء بيئة افتراضية
python -m venv venv
source venv/bin/activate  # في Windows: venv\Scripts\activate

# تثبيت التبعيات
pip install -r requirements.txt

# نسخ ملف البيئة
cp .env.example .env

# تحرير .env بتكوينك
nano .env

# تشغيل الترحيلات
alembic upgrade head

# بدء خادم الخلفية
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

يجب أن تعمل الخلفية الآن على `http://localhost:8000`

اختبرها:
```bash
curl http://localhost:8000/health
# يجب أن ترجع: {"status":"healthy"}
```

#### إعداد الواجهة الأمامية

```bash
# في نافذة طرفية جديدة
cd frontend

# تثبيت التبعيات
npm install

# نسخ ملف البيئة
cp .env.local.example .env.local

# تحرير .env.local
nano .env.local

# بدء خادم التطوير
npm run dev
```

يجب أن تعمل الواجهة الأمامية الآن على `http://localhost:3000`

**✅ نقطة التحقق**: كل من الخلفية والواجهة الأمامية تعمل محلياً.

### الخطوة 3: إجراء أول استدعاء API (15 دقيقة)

#### إنشاء مفتاح API

1. تسجيل الدخول إلى حسابك على `http://localhost:3000`
2. انتقل إلى الإعدادات ← مفاتيح API
3. انقر على "إنشاء مفتاح جديد"
4. انسخ المفتاح واحفظه بأمان

#### اختبار نقاط نهاية API

```bash
# تخزين مفتاح API الخاص بك
export API_KEY="your_api_key_here"

# اختبار نقطة نهاية مصادق عليها
curl -H "Authorization: Bearer $API_KEY" \
  http://localhost:8000/api/products

# اختبار إنشاء طلب
curl -X POST \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"product_id": "1", "quantity": 1}' \
  http://localhost:8000/api/orders

# عرض وثائق API
open http://localhost:8000/api/docs
```

**✅ نقطة التحقق**: إجراء استدعاءات API مصادق عليها بنجاح.

### الخطوة 4: بناء أول تكامل (30 دقيقة)

#### مثال: تكامل قائمة المنتجات

إنشاء تكامل بسيط يجلب ويعرض المنتجات:

```javascript
// my-integration.js
const BrainSAITClient = require('./brainsait-client');

const client = new BrainSAITClient({
  apiKey: process.env.BRAINSAIT_API_KEY,
  baseUrl: 'https://api.store.brainsait.io'
});

async function listProducts() {
  try {
    const products = await client.products.list({
      page: 1,
      per_page: 10
    });
    
    console.log('المنتجات:', products);
    return products;
  } catch (error) {
    console.error('خطأ:', error.message);
  }
}

listProducts();
```

#### مثال: معالج Webhook

```javascript
// webhook-handler.js
const express = require('express');
const app = express();

app.use(express.json());

app.post('/webhooks/brainsait', (req, res) => {
  const event = req.body;
  
  switch (event.type) {
    case 'order.created':
      console.log('طلب جديد:', event.data);
      // معالجة الطلب الجديد
      break;
      
    case 'payment.succeeded':
      console.log('الدفع ناجح:', event.data);
      // معالجة الدفع الناجح
      break;
      
    default:
      console.log('حدث غير معروف:', event.type);
  }
  
  res.json({ received: true });
});

app.listen(3000, () => {
  console.log('معالج Webhook يستمع على المنفذ 3000');
});
```

**✅ نقطة التحقق**: لقد قمت ببناء أول تكامل لك!

#### استلام حساب المستأجر

**✅ نقطة التحقق**: تم إنشاء حساب المستأجر واستلام بيانات الاعتماد.

### الخطوة 2: تكوين المستأجر (2-4 ساعات)

#### تخصيص العلامة التجارية

```bash
POST /api/admin/tenant/branding
{
  "company_name": "شركتك",
  "logo_url": "https://your-company.com/logo.png",
  "primary_color": "#0066cc",
  "secondary_color": "#00cc66",
  "custom_domain": "store.your-company.com"
}
```

#### تكوين SSO

**إعداد SAML:**
```bash
POST /api/admin/sso/configure
{
  "type": "saml",
  "entity_id": "https://your-idp.com/entity",
  "sso_url": "https://your-idp.com/sso",
  "certificate": "MIID..."
}
```

#### إدارة المستخدمين

```bash
# استيراد المستخدمين عبر CSV
POST /api/admin/users/import
Content-Type: multipart/form-data

# أو عبر API
POST /api/admin/users
{
  "email": "user@your-company.com",
  "name": "أحمد محمد",
  "role": "user",
  "department": "الهندسة"
}
```

**✅ نقطة التحقق**: تم تكوين المستأجر بالعلامة التجارية و SSO.

### الخطوة 3: التكامل والاختبار (4-6 ساعات)

#### تكامل API

```javascript
// عميل API للمؤسسات
const BrainSAIT = require('@brainsait/enterprise-sdk');

const client = new BrainSAIT({
  tenantId: 'your-tenant-id',
  apiKey: process.env.BRAINSAIT_API_KEY,
  environment: 'staging' // اختبر أولاً
});

// مزامنة المستخدمين من نظامك
await client.users.sync(yourUsers);

// تكوين webhooks
await client.webhooks.create({
  url: 'https://your-company.com/webhooks/brainsait',
  events: ['order.created', 'user.registered']
});
```

**✅ نقطة التحقق**: تم اختبار التكامل ويعمل في بيئة التدريج.

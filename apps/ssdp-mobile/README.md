# SSDP Mobile App

React Native mobile application for SSDP platform using Expo.

## Features

- Cross-platform (iOS & Android)
- Arabic/English bilingual support
- Offline-first architecture
- Push notifications
- Biometric authentication
- Real-time order tracking

## Setup

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run on Android
npm run android

# Run on iOS
npm run ios
```

## Architecture

- **Expo Router**: File-based routing
- **React Native**: Core framework
- **TypeScript**: Type safety
- **Expo modules**: Native capabilities

## Testing

```bash
npm test
```

## Build

```bash
# Android
npm run build:android

# iOS
npm run build:ios
```
